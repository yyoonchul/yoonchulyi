## 📝 Detailed Notes

### 1. Introducing Custom Agents

1. Antigravity positions Custom Agents as a division-of-labor tool for agentic software work.
   - The announcement says software engineering is shifting from writing individual lines of code toward orchestrating specialized agents.
   - Custom Agents have first-class support in Antigravity 2.0 and the Antigravity CLI; Antigravity IDE support is described as forthcoming.
   - The intended benefit is to let specialized agents act, verify work, and run tasks in parallel on more complex projects.
2. The feature addresses specialization and context-window costs in general-purpose assistants.
   - A general assistant must repeatedly be told a project’s testing conventions, dependency rules, and other local practices.
   - Putting every rule, linter setting, and test instruction into every chat creates unnecessary prompt-token overhead.
   - A Custom Agent instead defines a scoped role with its own instructions, tools, and constraints, keeping the active context more focused.
3. Agent definitions are portable, file-based workspace configuration.
   - Each agent is a Markdown file with YAML frontmatter; its Markdown body is compiled into the agent’s system prompt.
   - Project-level agents live in `.agents/agents/`, while user-global agents can live in `~/.gemini/config/agents/`.
   - Committing a project agent makes that standardized workflow available to teammates when they check out the repository.
4. Custom Agents complement rather than replace skills and dynamic subagents.
   - Skills can still add task-specific context progressively, and dynamic subagents can receive a one-off delegated prompt from a coordinator.
   - A Custom Agent can narrow the relevant set of skills, MCP servers, hooks, default tools, system instructions, model, and permissions for one specialization.
   - This creates a reusable worker definition instead of requiring a coordinator to recreate all of those choices for each delegation.
5. Antigravity adds execution symmetry, scoped command policy, and nested lifecycle hooks.
   - With `mainAgent: true` and `subagent: true`, a configured agent can be selected directly in the desktop app, invoked through `agy --agent`, or delegated by another agent.
   - `commandExecutionPolicy: auto` can allow ordinary test and compilation commands to run in the background, while high-risk actions such as deletion remain approval-gated.
   - `PreInvocation` and matcher-based `PreToolUse` hooks can run setup or verification commands at defined points in the agent lifecycle.

### 2. State of Open Models: Summer 2026 Observations

1. The Hub grew rapidly, but usage remained concentrated in a small minority of repositories.
   - The report examines activity observed during the first seven months of 2026 and was published on August 14.
   - Public model repositories rose from 2.43 million to 2.96 million; datasets rose from 711,000 to 1 million; Spaces rose from 1.00 million to 1.44 million.
   - About 85.6% of models had fewer than 200 lifetime downloads, while 1.5% of repositories accounted for 99.2% of all downloads.
2. The open-model frontier is increasingly shaped by Chinese labs, while U.S. organizations emphasize different layers.
   - In nearly every month of 2026, the largest and highest-performing open model released by a Chinese lab exceeded the largest release from an American lab.
   - The report puts China’s monthly ceiling between 754B and 2.78T parameters; U.S. releases stayed below 130B in five of seven months, apart from NVIDIA Nemotron 3 Ultra and Thinking Machines Lab’s Inkling.
   - AMD and NVIDIA each released more than 200 new model repositories, illustrating how hardware companies use open models to support their chip ecosystems.
3. Likes measure current attention, whereas downloads reveal embedded, durable use.
   - Exactly one repository appeared in both the top 25 lists by 2026 downloads and by likes.
   - No model published in 2026 reached the download top 25, and thirteen of those 25 repositories date from 2022.
   - `all-MiniLM-L6-v2` recorded 1.55 billion downloads in seven months with 5,156 likes, illustrating the difference between pipeline use and release excitement.
4. Qwen has become a broad community base model rather than merely a sequence of releases.
   - Qwen-based models account for 151,448 derivatives on the Hub: 2.6 times Meta’s total footprint and 4.7 times the Llama repositories specifically.
   - The report estimates Qwen derivatives increased by roughly 180–210 repositories per day through the first seven months of 2026.
   - Regular releases, broad model-size coverage, and Apache 2.0 licensing reinforce a developer feedback loop of fine-tuning, conversion, and reuse.
5. Small models remain the practical layer, even as local tooling and agents widen the ecosystem.
   - Models under 1B parameters account for 83% of all-time downloads among repositories that declare parameter counts; models above 100B account for 1%.
   - Hugging Face credits `llama.cpp` and its GGUF ecosystem with making much larger models practical across several consumer machines.
   - The July agent-usage data shows Claude Code at 44.4% of identified agent traffic and Codex at 20.8%, but the authors caution that Hub metrics are not direct measures of model quality, total adoption, or market share.

## 📝 상세 정리

### 1. 커스텀 에이전트(Custom Agents) 소개

1. Antigravity는 커스텀 에이전트를 에이전트 기반 소프트웨어 작업의 분업 도구로 제시한다.
   - 이 발표는 소프트웨어 엔지니어링이 개별 코드 줄을 쓰는 일에서 전문 에이전트를 조율하는 일로 옮겨 가고 있다고 설명한다.
   - 커스텀 에이전트는 Antigravity 2.0과 Antigravity CLI에서 우선 지원되며, Antigravity IDE 지원은 추후 제공한다고 밝힌다.
   - 목표는 전문 에이전트가 더 복잡한 프로젝트에서 작업을 수행하고 검증하며 병렬로 실행하게 하는 데 있다.
2. 이 기능은 범용 어시스턴트의 전문성 부족과 컨텍스트 윈도우 비용을 해결하려 한다.
   - 범용 어시스턴트에게는 프로젝트의 테스트 규칙, 의존성 관리 규칙, 그 밖의 로컬 관행을 반복해서 알려 주어야 한다.
   - 모든 규칙, 린터(linter) 설정, 테스트 지침을 모든 대화에 넣으면 프롬프트 토큰을 불필요하게 많이 사용하게 된다.
   - 커스텀 에이전트는 자체 지침·도구·제약 조건을 가진 범위가 명확한 역할을 정의해, 현재 컨텍스트를 더 집중된 상태로 유지한다.
3. 에이전트 정의는 이식 가능한 파일 기반 워크스페이스 설정이다.
   - 각 에이전트는 YAML 프런트매터를 포함한 Markdown 파일이며, 본문은 에이전트의 시스템 프롬프트로 컴파일된다.
   - 프로젝트 수준 에이전트는 `.agents/agents/`에, 사용자 전역 에이전트는 `~/.gemini/config/agents/`에 둘 수 있다.
   - 프로젝트 에이전트를 커밋하면 팀원이 저장소를 내려받을 때 표준화된 작업 흐름을 사용할 수 있다.
4. 커스텀 에이전트는 스킬과 동적 하위 에이전트를 대체하기보다 보완한다.
   - 스킬은 계속해서 작업별 맥락을 점진적으로 추가할 수 있고, 동적 하위 에이전트는 조율 에이전트로부터 일회성 위임 프롬프트를 받을 수 있다.
   - 커스텀 에이전트는 특정 전문 역할에 필요한 스킬, MCP 서버, 훅, 기본 도구, 시스템 지침, 모델, 권한의 범위를 좁힐 수 있다.
   - 따라서 조율 에이전트가 위임할 때마다 모든 선택을 다시 구성하지 않아도 되는 재사용 가능한 작업자 정의가 된다.
5. Antigravity는 실행 대칭성, 범위가 정해진 명령 정책, 중첩 수명 주기 훅을 추가한다.
   - `mainAgent: true`와 `subagent: true`를 설정하면 해당 에이전트를 데스크톱 앱에서 직접 선택하거나 `agy --agent`로 실행하거나 다른 에이전트가 위임할 수 있다.
   - `commandExecutionPolicy: auto`는 일반적인 테스트와 컴파일 명령을 백그라운드에서 실행하게 할 수 있지만, 파일 삭제 같은 고위험 작업은 승인 절차를 유지한다.
   - `PreInvocation`과 매처 기반 `PreToolUse` 훅은 에이전트 수명 주기의 정해진 지점에서 설정 또는 검증 명령을 실행할 수 있다.

### 2. 오픈 모델 현황: 2026년 여름 관찰

1. Hub은 빠르게 성장했지만, 사용량은 소수 저장소에 집중된 상태였다.
   - 이 보고서는 2026년 첫 7개월 동안 관찰한 활동을 분석했으며 8월 14일에 게시됐다.
   - 공개 모델 저장소는 243만 개에서 296만 개로, 데이터세트는 71만 1천 개에서 100만 개로, Spaces는 100만 개에서 144만 개로 늘었다.
   - 모델의 약 85.6%는 누적 내려받기 200회 미만이었고, 저장소 1.5%가 전체 내려받기의 99.2%를 차지했다.
2. 오픈 모델의 최전선은 중국 연구소가 점점 더 주도하는 반면, 미국 조직은 다른 계층에 힘을 싣는다.
   - 2026년 거의 모든 달에 중국 연구소가 공개한 최대·최고 성능 오픈 모델은 미국 연구소의 최대 공개 모델보다 컸다.
   - 보고서는 중국의 월별 최대 규모를 7,540억~2조 7,800억 매개변수로 제시하며, 미국의 공개 모델은 NVIDIA Nemotron 3 Ultra와 Thinking Machines Lab의 Inkling을 제외한 7개월 중 5개월에 1,300억 매개변수 미만이었다.
   - AMD와 NVIDIA는 각각 200개가 넘는 새 모델 저장소를 공개해, 하드웨어 기업이 오픈 모델로 자사 칩 생태계를 지원하는 방식을 보여 준다.
3. 좋아요는 현재의 관심을, 내려받기는 내장돼 지속되는 사용을 측정한다.
   - 2026년 내려받기 기준 상위 25개와 좋아요 기준 상위 25개 목록에 동시에 들어간 저장소는 정확히 하나였다.
   - 2026년에 게시된 모델 중 내려받기 상위 25위에 든 모델은 없었고, 그 25개 가운데 13개는 2022년에 나온 저장소다.
   - `all-MiniLM-L6-v2`는 7개월 동안 15억 5천만 회 내려받기와 좋아요 5,156개를 기록해, 파이프라인 사용과 출시 직후의 관심이 다름을 보여 준다.
4. Qwen은 단순한 모델 출시 연속이 아니라 폭넓은 커뮤니티 기반 모델이 됐다.
   - Qwen 기반 모델은 Hub에서 파생 모델 151,448개를 차지하며, 이는 Meta 전체 규모의 2.6배이자 Llama 저장소만 비교하면 4.7배다.
   - 보고서는 2026년 첫 7개월 내내 Qwen 파생 모델이 하루 약 180~210개 저장소씩 늘었다고 추정한다.
   - 규칙적인 출시, 폭넓은 모델 크기 선택지, Apache 2.0 라이선스는 미세 조정·변환·재사용으로 이어지는 개발자 선순환을 강화한다.
5. 로컬 도구와 에이전트가 생태계를 넓히는 가운데에도 소형 모델은 실용 계층으로 남아 있다.
   - 매개변수 수를 밝힌 저장소 중 10억 개 미만 모델은 전체 기간 내려받기의 83%를 차지했고, 1,000억 개 초과 모델은 1%를 차지했다.
   - Hugging Face는 `llama.cpp`와 GGUF 생태계가 훨씬 큰 모델도 여러 소비자용 기기에 걸쳐 실용적으로 실행할 수 있게 했다고 평가한다.
   - 7월 에이전트 사용 데이터에서 Claude Code는 식별된 에이전트 트래픽의 44.4%, Codex는 20.8%였지만, 저자들은 Hub 지표가 모델 품질·전체 채택·시장 점유율을 직접 측정하는 값은 아니라고 경고한다.
