## 📋 Quick Summary

### Deepseek releases experimental Flash vision model that rivals Opus 4.8 on agent benchmarks
**Source:** The Decoder · **Category:** AI · **Link:** [Original](https://the-decoder.com/deepseek-releases-experimental-flash-vision-model-that-rivals-opus-4-8-on-agent-benchmarks/)
- DeepSeek released V4-Flash-Vision-Exp, an experimental multimodal extension of V4-Flash that adds image understanding while retaining the base model’s text capabilities.
- DeepSeek positions the model for visual agent workflows; on the company’s internal multimodal agent benchmarks, it comes close to Claude Opus 4.8 and occasionally exceeds it.
- The release supports OpenAI-compatible and Anthropic-compatible endpoints, accepts up to 600 images per request, and caps image processing at 384 tokens per image.

## 📝 Detailed Notes

### 1. Deepseek releases experimental Flash vision model that rivals Opus 4.8 on agent benchmarks

1. DeepSeek has added vision to its experimental Flash model line.
   - The new model is named DeepSeek-V4-Flash-Vision-Exp.
   - It is an experimental multimodal extension of DeepSeek-V4-Flash.
   - DeepSeek says the vision variant preserves the base model’s text performance in reasoning and world knowledge.
   - Its stated addition is image understanding alongside those text capabilities.
2. The company is aiming at agents that must reason over visual inputs and use tools.
   - DeepSeek describes the model as compatible with different agent frameworks.
   - It combines visual understanding with tool use rather than treating image analysis as an isolated feature.
   - The cited use cases include describing images, extracting text from screenshots, and analyzing diagrams.
   - The model accepts JPEG, PNG, GIF, and WebP images.
3. DeepSeek reports competitive results, but the comparison is based on its own benchmarks.
   - On DeepSeek’s internal multimodal agent benchmarks, V4-Flash-Vision-Exp nearly matches Claude Opus 4.8 on agent tasks.
   - The company’s benchmark graphic indicates that the new model sometimes surpasses Opus 4.8.
   - These claims should be read as vendor-reported results rather than an independent evaluation.
   - The article does not provide external benchmark replication or broader model-quality measurements.
4. The API is designed for compatibility and flexible image submission.
   - The model works with OpenAI’s Chat Completions and Responses APIs and Anthropic’s Messages endpoint.
   - DeepSeek also released version 0.1.1 of its Harness framework, which supports the model out of the box.
   - Developers can send images as Base64 data, public URLs, or references through the new Files API.
   - The Files API is free, permits files up to 64 MiB, and lets an uploaded file be reused by ID across requests.
5. Image handling is constrained to make cost and scale more predictable.
   - Publicly accessible image URLs may be up to 32 MiB.
   - An optional `detail` field downsizes an image to 512 × 512 pixels when fine detail is unnecessary.
   - Before processing, the model normalizes images to roughly 800 × 800 pixels according to aspect ratio.
   - Each image costs at most 384 tokens, and pricing follows V4-Flash rates.
   - A request can include up to 600 images; the per-side edge limit is 8,192 pixels, or 4,096 pixels when a request has 15 or more images.

## 📝 상세 정리

### 1. DeepSeek, 에이전트 벤치마크에서 Opus 4.8에 맞서는 실험적 Flash 비전 모델 출시

1. 딥시크(DeepSeek)는 실험적 Flash 모델 계열에 시각 기능을 추가했다.
   - 새 모델의 이름은 DeepSeek-V4-Flash-Vision-Exp다.
   - 이 모델은 DeepSeek-V4-Flash를 확장한 실험적 멀티모달 모델이다.
   - 딥시크는 비전 모델이 추론과 세계 지식에서 기반 모델의 텍스트 성능을 유지한다고 설명한다.
   - 여기에 이미지 이해 기능을 추가한 것이 이 모델의 핵심 변화다.
2. 회사는 시각 입력을 해석하고 도구를 쓰는 에이전트를 주요 대상으로 삼았다.
   - 딥시크는 이 모델이 여러 에이전트 프레임워크(agent framework)와 호환된다고 설명한다.
   - 이미지 분석을 독립 기능으로 두기보다 시각 이해와 도구 사용(tool use)을 결합한다.
   - 제시한 활용 사례에는 이미지 설명, 스크린샷의 텍스트 추출, 다이어그램 분석이 포함된다.
   - 모델은 JPEG, PNG, GIF, WebP 이미지 형식을 지원한다.
3. 딥시크는 경쟁력 있는 결과를 보고했지만, 비교는 회사 자체 벤치마크에 근거한다.
   - 딥시크의 내부 멀티모달 에이전트 벤치마크에서 V4-Flash-Vision-Exp는 에이전트 작업 기준으로 클로드 오퍼스 4.8(Claude Opus 4.8)에 근접했다.
   - 회사의 벤치마크 그래프는 새 모델이 일부 항목에서 Opus 4.8을 앞선다고 제시한다.
   - 이 결과는 독립 평가가 아니라 공급사가 보고한 수치로 해석해야 한다.
   - 기사에는 외부 재현 결과나 더 폭넓은 모델 품질 측정치는 제시되지 않았다.
4. API는 호환성과 유연한 이미지 전달 방식을 갖추도록 설계됐다.
   - 모델은 OpenAI의 Chat Completions API와 Responses API, Anthropic의 Messages 엔드포인트(endpoint)에서 작동한다.
   - 딥시크는 이 모델을 즉시 지원하는 Harness 프레임워크(framework) 0.1.1도 함께 공개했다.
   - 개발자는 Base64 데이터, 공개 URL, 새 Files API의 참조 방식으로 이미지를 보낼 수 있다.
   - Files API는 무료이며 최대 64MiB 파일을 허용하고, 한 번 올린 파일을 ID로 여러 요청에서 재사용하게 한다.
5. 이미지 처리에는 비용과 규모를 예측 가능하게 하는 제한이 적용된다.
   - 공개 접근 가능한 이미지 URL의 크기는 최대 32MiB까지다.
   - 세부 묘사가 필요하지 않으면 선택적 `detail` 필드로 이미지를 512 × 512픽셀로 축소할 수 있다.
   - 모델은 처리 전에 종횡비에 따라 이미지를 약 800 × 800픽셀 수준으로 정규화한다.
   - 이미지 한 장은 최대 384토큰을 쓰며, 가격은 V4-Flash 요율을 따른다.
   - 한 요청에는 최대 600장의 이미지를 넣을 수 있고, 한 변의 최대 길이는 8,192픽셀이지만 이미지가 15장 이상이면 4,096픽셀로 낮아진다.
